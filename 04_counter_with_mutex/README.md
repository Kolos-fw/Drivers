# 04. Counter with Mutex (Счетчик с защитой)

Этот проект — эволюция `03_hello_counter`. Мы добавили **мьютекс (mutex)**, чтобы сделать драйвер потокобезопасным (thread-safe). Теперь он готов к работе в условиях, когда к нему одновременно обращаются несколько процессов.

## Что делает драйвер?

Функционал тот же, что и в предыдущем проекте:
1. При чтении из `/dev/counter` возвращает строку `Current value: N` и увеличивает счетчик.
2. При записи в устройство сбрасывает счетчик в 0.
3. **НОВОЕ:** Все операции с глобальной переменной `counter` защищены мьютексом `my_lock`.

## Ключевые концепции, изученные в проекте

*   **`struct mutex` и `mutex_init()`:** Объявление и инициализация мьютекса в ядре.
*   **`mutex_lock_interruptible()`:** Захват замка. Используется именно `interruptible`-версия, чтобы процесс можно было прервать сигналом (например, `Ctrl+C`), иначе система могла бы зависнуть навсегда.
*   **`mutex_unlock()`:** Освобождение замка. **Критически важно** вызывать его на всех путях выхода из функции, иначе произойдет deadlock (взаимная блокировка).
*   **Разделение критической секции:** Мы защищаем только изменение данных (инкремент счетчика), но отпускаем замок **до** вызова `simple_read_from_buffer`. Копирование данных в user space может занять время, и мы не хотим блокировать другие процессы на этот период.
