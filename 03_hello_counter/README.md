# 03. Hello Counter (Драйвер-счетчик)

Этот проект — логическое продолжение `02_hello_driver`. Здесь мы учимся **хранить состояние** внутри драйвера и правильно обрабатывать позицию чтения (`offset`).

## Что делает драйвер?

1. При каждом чтении из `/dev/my_hello` (например, через `sudo cat /dev/my_hello`) драйвер возвращает строку вида `Current value: N`, где `N` — это число, которое увеличивается на 1 при каждом новом чтении.
2. При записи в устройство (например, `echo "reset" | sudo tee /dev/my_hello`) счетчик сбрасывается в 0.
3. При выгрузке модуля состояние сбрасывается (так как переменные живут только пока модуль загружен).

## Ключевые концепции, изученные в проекте

*   **Хранение состояния (State):** Глобальная переменная `counter` живет в памяти ядра. Она сохраняет значение между вызовами системных функций `read` и `write`, пока модуль загружен.
*   **Смещение (Offset) и `simple_read_from_buffer`:** В предыдущем проекте мы вручную управляли `*offset` и использовали `copy_to_user`. В этом проекте мы используем стандартную функцию ядра `simple_read_from_buffer()`. Она автоматически обрабатывает `offset`, `count` и безопасно копирует данные, избавляя от необходимости писать «костыли».
*   **Кодировки в ядре:** В ходе разработки выяснилось, что использование кириллицы в `printk` и `snprintf` внутри ядра может приводить к «кракозябрам» в терминале.
