# Drivers

Репозиторий для самообучения разработке драйверов Linux.

## Содержимое

*   `01_hello_world/` — первый модуль ядра (Hello World). Выводит приветствие в `dmesg` при загрузке и прощание при выгрузке.
*   `02_hello_driver/` — первый символьный драйвер (Character Device). Создает устройство `/dev/my_hello`, позволяет записывать и читать из него данные, демонстрирует передачу данных между пространством пользователя и ядром.
