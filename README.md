# Drivers

Репозиторий для самообучения разработке драйверов Linux.

## Содержимое

*   `01_hello_world/` — первый модуль ядра (Hello World). Выводит приветствие в `dmesg` при загрузке и прощание при выгрузке.
*   `02_hello_driver/` — первый символьный драйвер (Character Device). Создает устройство `/dev/my_hello`, позволяет записывать и читать из него данные, демонстрирует передачу данных между пространством пользователя и ядром.
*   `03_hello_counter/` — драйвер-счетчик. Демонстрирует хранение состояния в ядре (глобальные переменные) и работу с `offset` при чтении. Использует `simple_read_from_buffer` для безопасной передачи данных в user space.
*   `04_counter_with_mutex/` — драйвер-счетчик с защитой от гонок данных (Race Conditions). Демонстрирует использование мьютексов (`mutex`) в ядре Linux для синхронизации доступа к общим данным между несколькими процессами.

## Общая инструкция по сборке и запуску

Все проекты собираются одинаково. Для сборки вам понадобятся заголовки ядра (`linux-headers`) и компилятор (`build-essential`).

**Перейдите в папку с нужным проектом:**
```bash
cd 01_hello_world # или 02_hello_driver и т.д.
make
sudo insmod <имя_файла>.ko
sudo cat /dev/<имя_девайса> //Для чтения
echo "data" | sudo tee /dev/<имя_девайса> //Для записи
sudo dmesg | tail -5
sudo rmmod <имя_модуля>
make clean
