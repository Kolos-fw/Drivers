# 01. Hello World (Модуль ядра)

Это самый первый и базовый проект в моем пути изучения разработки драйверов Linux. 
Здесь нет работы с устройствами или железом — только демонстрация того, как код загружается в ядро и выгружается из него.

## Что делает модуль?

Модуль ядра (Kernel Module) — это код, который можно динамически подключить к работающему ядру без перезагрузки системы.
Этот конкретный модуль делает всего две вещи:
1. При загрузке (`insmod`) пишет приветствие в лог ядра.
2. При выгрузке (`rmmod`) пишет прощание в лог ядра.

## Ключевые понятия

- **`module_init` / `module_exit`** — макросы, которые указывают ядру, какие функции вызывать при загрузке и выгрузке модуля. У модулей ядра нет функции `main()`, как у обычных программ.
- **`printk`** — это функция вывода для ядра (аналог `printf` в пользовательском пространстве). Она пишет сообщения не в терминал, а в кольцевой буфер ядра.
- **`dmesg`** — утилита для просмотра этого буфера.
- **`__init` / `__exit`** — специальные атрибуты функций, которые подсказывают компилятору, что код нужен только при инициализации или только при выгрузке (позволяет экономить память ядра).

## Как собрать и протестировать

**1. Сборка модуля:**
```bash
cd 01_hello_world
make
sudo insmod hello.ko
sudo dmesg | tail -3  # "Привет, ядро! Модуль загружен."
sudo rmmod hello
sudo dmesg | tail -3  # "Пока, ядро! Модуль выгружен."
make clean
